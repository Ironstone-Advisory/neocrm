# Plan, work, run, and handoff

A **Plan** is a versioned, ordered or partially ordered approach to a Goal. Each **PlanStep** declares dependencies, assigned Actors, necessary context, required capability/authority, policy gate, time/cost budget, expected output/Outcome, completion rule, and failure/escalation path.

A **WorkItem** is a bounded unit of human or Agent work with owner, state, priority, due/expiry, linked Goal/Plan, inputs, outputs, policy, and Outcome. It is not a Commitment: a Commitment is a promise to a beneficiary. It is not an Action: an Action is an intended system effect.

A **Handoff** transfers accepted responsibility or work. It includes source/target Actors, scope, necessary ContextSnapshot references, evidence, open questions, authority, budget, expected output, acceptance, deadline, and escalation.

A **CollaborationSession** groups people, Agents, Goal, Plan, shared work state, decisions, corrections, approvals, and Outcomes within an explicit purpose and retention boundary.
