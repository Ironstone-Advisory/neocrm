# Views and workspaces

**Status:** Proposed experience architecture

Views are task-specific projections over shared canonical objects. They may collect user input and corrections but do not create competing domain models.

| View | Primary job |
| --- | --- |
| Relationship Workspace | Understand a Party/Relationship, Goals, Needs, roles, health evidence, current work, commitments, and Outcomes. |
| Agent Collaboration Workbench | See contributing Agents, purpose, Delegation, Plan, Handoffs, evidence, budgets, uncertainty, and escalations. |
| Goal / Plan Board | Frame desired Outcomes, constraints, dependencies, owners, progress, and trade-offs. |
| Human Work Queue | Prioritize WorkItems, exceptions, corrections, and decisions requiring human judgment. |
| Approval Inbox | Review exact action previews, risk, evidence, policy rationale, expiry, and alternatives. |
| Insight Explorer | Inspect Signals, Insights, supporting/contradicting evidence, expiry, disposition, and outcome links. |
| Relationship Graph | Explore Parties, roles, relationships, work, commercial/service state, and provenance-aware paths. |
| Timeline / Conversation | Reconstruct Activities, Messages, Conversation episodes, changes, commitments, decisions, and outcomes over time. |
| Calendar / Time / Capacity | Project Events, Commitments, Availability, Capacity, Workload, deadlines, and focus recommendations. |
| Commercial Workspace | Work with CustomerNeeds, Offers, Opportunities, Deals, Contracts, commitments, and revenue/customer Outcomes. |
| Service Workspace | Work with ServiceCases, entitlements, SLAs, requests, resolution, commitments, and customer effort. |
| Campaign / Engagement Workspace | Define Goals, consented Audiences, Journey stages, Activities, content, suppression, and engagement Outcomes. |
| Evidence / Provenance Inspector | Inspect source, authority, freshness, confidence, completeness, epistemic category, transformations, conflicts, and access state. |
| Agent Audit Console | Trace Triggers, Runs, Steps, Handoffs, ContextSnapshots, PolicyDecisions, Approvals, Actions, budgets, failures, and versions. |
| Outcome / Learning Dashboard | Compare intended/observed Outcomes, customer/business/ethical measures, LearningSignals, evaluations, and change decisions. |
| Integration / Mapping Administration | Manage source capabilities, mappings, authority, allowlists, consent/retention rules, health, and substitution tests. |

Conversation may open or operate any of these views, but cannot bypass their semantic, evidence, policy, or approval contracts.
