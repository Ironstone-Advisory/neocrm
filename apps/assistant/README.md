# CAP-001 conversational reference shell

This app accepts the relationship-brief question, delegates deterministic context assembly to the CAP-001 context engine, and renders the structured response categories.

It is not a production chat service, LLM integration, general Agent Runtime, complete RIL, or the NeoCRM product. It has no live Zoho/Obsidian access, proactive triggers, specialist Agents, durable memory, or external writes.

See the [conversational experience](../../spec/experience/conversational-experience.md) and [CAP-001 runtime](../../spec/capabilities/CAP-001-relationship-brief/runtime.md).
