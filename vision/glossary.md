# Glossary

| Term | Meaning |
| --- | --- |
| Adapter | Boundary component that translates an external system into or from canonical NeoCRM semantics. |
| Activity | A recorded interaction or event involving one or more parties. |
| Action | A proposed or executed intentional change, such as sending a message or creating a commitment. |
| Canonical model | NeoCRM's vendor-independent domain vocabulary and relationships. |
| Commitment | A promise, obligation, or planned follow-up with a responsible party and temporal expectation. |
| Conversation | A related sequence of activities that form a coherent interaction episode. |
| Party | An entity able to participate in a relationship, activity, commercial matter, commitment, or action. |
| Provenance | Origin, retrieval time, method, and transformation lineage of an assertion. |
| Relationship Intelligence Layer | The layer that resolves entities, assembles context, reasons within policy, and orchestrates governed actions. |
| Role | A business meaning held by a Party in a context, such as Customer, Partner, Employee, or Contract Party. |
