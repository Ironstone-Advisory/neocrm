# Publication figure

## Figure 1 — NeoCRM's seven-layer architecture

**Caption:** NeoCRM separates seven logical responsibilities while Canonical Semantics and Governance/Control cross the stack. The Relationship Intelligence Layer spans Agent, Relationship Orchestration, and Context/Data Access, but those layers retain distinct contracts and trust boundaries.

**Alt text:** Vertical architecture diagram with seven labelled layers. Presentation sits at the top, followed by Agent, Relationship Orchestration, Context and Data Access, Hybrid Storage, Integration and Ecosystem, and Infrastructure and Resilience. A boundary labelled Relationship Intelligence Layer surrounds Layers 2 through 4. Canonical Semantics and Governance and Control connect across the stack with dashed lines. Every layer has a text label, so meaning does not depend on colour.
