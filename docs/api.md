# Historical API scaffold

NeoCRM v0.1 does not standardize a production REST API. The existing health/meta endpoints are a local probe only.

Future APIs and adapters must support semantic identity resolution, provenance-aware context retrieval, distinction of fact/observation/hypothesis/unknown, policy evaluation, action preview, approval, execution, verification, and audit. See [the adapter model](../architecture/adapter-model.md) and [provenance/policy model](../architecture/provenance-and-policy.md).
