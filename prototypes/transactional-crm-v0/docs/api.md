# Archived API scaffold

The Fastify health/meta endpoints are preserved as a local transactional prototype. NeoCRM v0.1 does not standardize this REST API and it is outside the active workspace.

Current integration boundaries are defined by the [adapter model](../../../spec/architecture/adapter-model.md), [integration/events architecture](../../../spec/architecture/integration-and-events.md), and [security/governance](../../../spec/architecture/security-and-governance.md).
