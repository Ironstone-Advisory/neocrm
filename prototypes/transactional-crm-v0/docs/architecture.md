# Archived implementation scaffold

This prototype started with a TypeScript/Fastify modular monolith and PostgreSQL schema. It is useful history, not the authoritative NeoCRM architecture.

The active baseline is the [seven-layer architecture](../../../spec/architecture/seven-layer-architecture.md) with an Agent layer, Relationship Orchestration, Context/Data Access, replaceable Hybrid Data Storage, Integration, Infrastructure, Canonical Semantics, and Governance/Control.
