# Skills

Agent skills that let people use NeoCRM workflows today, by pasting or uploading their own material, before any connector or runtime exists. Each skill is a `SKILL.md` in the open Agent Skills format and runs in any compatible host.

A skill here is a front end, not product authority. It must follow the workflow definitions and the [specification](../spec/README.md); where they differ, the specification wins.
