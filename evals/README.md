# Evaluations

EVAL-001 is a deterministic structural evaluation for CAP-001. It checks
grounding, provenance, epistemic separation, conflict handling, unknown
honesty, source-failure visibility, memory, and action safety. It does not
replace the blinded human usefulness evaluation described by EXP-006.

`run-eval.mjs` exports a reusable evaluator and can run as a command after the
reference assistant is installed.
