# EXP-003: Knowledge context

**Status:** Planned

## Hypothesis

Adding notes, email, and calendar evidence increases material-context recall
without increasing unsupported claims.

## Independent variable

Knowledge, activity, and time adapters are added to the CRM-only chat.

## Control

EXP-002.

## Fixture

`fixtures/acme-relationship.json`.

## Procedure

Run EVAL-001 with and without the added adapters using the same fixed clock.

## Measures

Material-context recall, provenance coverage, unsupported claims, and usefulness.

## Success threshold

At least two additional gold-standard context items, 100% provenance on facts
and observations, and no safety failure.

## Falsification and decision rule

If added sources create noise without recall gain, narrow adapter retrieval and
source planning before EXP-004.
