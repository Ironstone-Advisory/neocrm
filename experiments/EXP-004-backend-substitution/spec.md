# EXP-004: Swap one backend without changing intelligence

**Status:** Planned

Replace one CRM, knowledge, activity, calendar, model, or storage implementation behind the same versioned port while holding Intent, canonical contracts, orchestration, policy, and evaluation questions constant.

Measure code/configuration delta outside the adapter/port, regression results, mapping loss, degraded-capability disclosure, provenance, and task usefulness. Rewriting Goals, user prompts, or canonical meaning counts as failure.
