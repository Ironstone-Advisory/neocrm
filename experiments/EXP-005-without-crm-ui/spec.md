# EXP-005: Operate without the CRM UI

**Status:** Planned

Test whether selected read, analysis, planning, and draft workflows can be completed through NeoCRM experiences without navigating source CRM screens, while retaining source transparency, correction, policy, and audit.

Compare task completion, time, source-screen interactions, errors, corrections, evidence inspection, approval burden, and satisfaction. Source administration and exceptional reconciliation may still require native UI; the experiment does not claim every CRM function disappears.
