# EXP-002: Google Sheets + web knowledge substrate

**Status:** Planned

Test whether a deliberately primitive tabbed Google Sheet plus permissioned web/Markdown knowledge can support the same canonical relationship tasks as the initial operational/knowledge substrates.

Hold questions and scenarios constant. Compare CTS pass rate, mapping loss, setup/maintenance effort, provenance coverage, latency, and user usefulness. Vendor terms must not leak into the primary task model. Failure supports narrowing portability claims, not adding Sheet-specific semantics.
