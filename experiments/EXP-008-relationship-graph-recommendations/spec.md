# EXP-008: Relationship-graph recommendations

**Status:** Planned

Test whether governed multi-hop relationships among Parties, Roles, Activities, Knowledge, Needs, work, commercial/service state, and Outcomes produce useful Recommendations that isolated records miss.

Compare relevance, novelty, explanation/path quality, false positives, sensitive-link leakage, customer-harm risk, and incremental value over a list/record view. Graph proximity alone must never imply trust, influence, consent, or action permission.
