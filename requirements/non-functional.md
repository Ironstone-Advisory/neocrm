# Quality Requirements

| Concern | Requirement |
| --- | --- |
| Portability | Replacing one adapter must not require changing the canonical semantic model or user intent. |
| Explainability | Material claims and recommendations must be traceable to sources, transformations, and reasoning boundaries. |
| Privacy | Data minimization, consent, retention, and access rules must be enforceable per source and action. |
| Security | Credentials remain within adapters; least privilege and auditable access are required. |
| Reliability | Failure or stale data from one source must be visible and must not be silently represented as absence. |
| Human control | External writes are previewable, authorized, and auditable. |
| Interoperability | The model supports bidirectional mapping while retaining native source identifiers and provenance. |
